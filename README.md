# 📷 Kamera Live – Releases

Hier liegen die fertigen Android-APKs von **Kamera Live** (Live-Bild von Spiegelreflex-, System- und Kompaktkameras über USB-OTG).

- Neueste Version: **[Releases](../../releases/latest)** → `Kamera-Live-<Version>.apk` herunterladen und installieren.
- Die App aktualisiert sich danach selbst: Sie gleicht sich beim Start und alle 6 Stunden mit diesen Releases ab – ohne GitHub-Konto oder Token.
- Jede APK ist mit demselben Schlüssel signiert; die App prüft vor der Installation SHA-256, Paketname und Versionsnummer.

Der Quellcode liegt in einem privaten Repository.
